# docs/Runbooks/ — Procedure operative ripetibili

| File | Scopo |
|---|---|
| `APP_PROVISIONING_RUNBOOK.md` | Onboarding completo di un nuovo cliente, da zero ad APK installato |
| `BETA_TESTING_GUIDE.md` | Guida per tester esterni (installazione, invio feedback) |
| `BETA_DEBUG_RUNBOOK.md` | Troubleshooting build fallite |

Un runbook descrive una procedura ripetibile, non uno snapshot di un'esecuzione specifica — vedi `PROJECT_STANDARD.md` §6. Procedure che toccano infrastruttura/segreti restano in [`platform-infra/runbooks/`](../../platform-infra/runbooks/), non qui.
